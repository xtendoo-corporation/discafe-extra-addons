Loyalty Program Amortization

Agrega campo de amortización a programas Buy X Get Y

Este módulo extiende los programas de fidelidad de Odoo 18 para agregar un campo booleano "Amortización" que solo es visible cuando el tipo de promoción es "Comprar X recibir Y" (buy_x_get_y).

Características

  • Campo booleano "Amortización" agregado al modelo loyalty.program
  • Visibilidad condicional: solo aparece con tipo "Buy X Get Y"
  • Integración perfecta en la vista del formulario existente
  • Compatible con Odoo 18 Community

Uso:
1. Ir a Ventas > Programas de descuento y fidelidad
2. Crear/editar un programa
3. Seleccionar tipo "Buy X Get Y"
4. El campo "Amortización" aparecerá automáticamente
